# Android project

This native project is generated and synchronized by Capacitor 8.6.2. Build the debug APK from `DackyMobile/` with `python3 /workspace/.toolchains/run-with-gradle-proxy.py npm run android:build:debug`. See `docs/BUILD_GUIDE.md` for the pinned JDK, Android SDK and Gradle versions. The current APK has passed static package/signature checks but has not been installed on a device. Keep `local.properties`, signing keys and machine-local state out of Git.
