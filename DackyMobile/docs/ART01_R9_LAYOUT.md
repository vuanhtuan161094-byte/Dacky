# R9 — owner-approved terraced city

Replaces geometric diamond board with a broad multi-level walled capital: rear palace on high terrace, central ceremonial plaza/stairs, civic wings and front military district. Outer map separates woodland, rocky mineral hills, irrigated farmland and foundry. Shared layout coordinates and per-building footprint used by both renderer and deterministic terrain generator. 27 source-derived sprites get transparent-margin trim, bounded resampling, shared color treatment and explicit foot anchors; level tiers change displayed size and grade (not unique redrawn level sprites). No engine/catalog/save changes, no merge. HUD stays independently hideable with compact default orders. Actual visual acceptance still requires runtime screenshots and owner review.
