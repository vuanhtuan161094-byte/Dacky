# Normalized research data

Each JSON file uses schemaVersion 1 and carries observedAt plus source/evidence labels. LIVE_UI means an authenticated UI rule was visible; PUBLIC_CLIENT means only a public client module exposed the label or text; DACKY_CODE is an implementation audit. UNKNOWN fields are intentionally null or named in unknown arrays. IDs are retained only where they appear in the local Dacky mapping; live reward icons without tooltips keep null IDs.
